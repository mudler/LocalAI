# Icon source

Not a logo. `icon.png` is a generated tile: a cluster glyph (three boxes joined by lines) from the add-on icon set (`addons/internal/uibuild/glyphs.mjs`) on the add-on colour.

Why no brand mark: the Kubernetes logo is a trademark of the Linux Foundation, and the add-on should not use it as its own. A generic cluster glyph says what the add-on does.
