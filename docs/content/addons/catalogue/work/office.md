The Simple Office add-on (ID `office`) lets a chat make, read and edit Word, Excel, PowerPoint and PDF files. It does not need a Sandbox. In the current development builds, it is in the development channel of the add-on library, so it can change.

## At a glance

| Topic | Detail |
|---|---|
| What it adds | 11 tools: read, edit and create for Word, Excel and PowerPoint, and read and create for PDF. Files are saved in your files. It runs on Linux and macOS. |
| Who installs it | An administrator, from **Add-ons**, **Find add-ons**, with **Install and turn on**. With authentication off, you are the administrator. |
| Who turns it on | A person needs the `addons` feature. It is off by default for new users on a server with accounts. The person switches the add-on on for a chat in the **Tools** menu. A saved agent uses it only when you name it in the agent. |
| Guide | [Office documents]({{% relref "/features/files-and-documents/office" %}}) |

The Sandbox add-on can make the same files with Python and gives full control of the layout. The two add-ons work on their own. See [Sandbox: run Python on your files]({{% relref "/addons/catalogue/work/sandbox" %}}).
