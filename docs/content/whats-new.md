LocalAI news is published in two places, both kept current:

- **[Blog](https://localai.io/blog/)** for release write-ups, benchmark reports and engineering notes.
- **[GitHub Releases](https://github.com/mudler/LocalAI/releases)** for the full changelog of every version.

For how the project got here, read [LocalAI, from March 2023 to now](https://localai.io/blog/localai-since-march-2023/).

## What changed since 4.12

LocalAI now answers and does the work, on your own hardware. The main pages:

- [Work with a chat]({{% relref "features/chat-control" %}}): keep typing while it works, approve what lasts, hand work to sub-agents.
- [Use add-ons]({{% relref "features/using-addons" %}}): install Sandbox, Simple Office, Studio, Talk and more from a signed library.
- [Sandbox]({{% relref "features/sandbox" %}}) and [Office documents]({{% relref "features/office-documents" %}}): run code in isolation and make Word, Excel, PowerPoint and PDF files.
- [Users and what each can do]({{% relref "features/users-and-features" %}}): several people on one server, with features switched on per user.
- [Make LocalAI yours]({{% relref "features/make-localai-yours" %}}) and [Pages]({{% relref "features/pages" %}}): persona, shortcuts, Home widgets and small tools of your own.
- [Connectors]({{% relref "features/chats-connectors" %}}): talk to a saved agent from Slack, Telegram or Discord.
- [Short memory]({{% relref "features/short-memory" %}}): notes about you, saved after you confirm.

This page used to carry a hand-maintained highlights list. It drifted against the blog and the releases, so the list above is short and links to the pages that stay current.
