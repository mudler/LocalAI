One API

Change the base URL. Keep your client.

Any OpenAI client works. The same server also does speech, images, video and music.

Try the API →API docs →

python
1 from openai import OpenAI
2 client = OpenAI(
      base_url="http://localhost:8080/v1",
      api_key="none")
3 chat = client.chat.completions.create(
      model="gemma-4-e2b-it-qat-q4_0",
      messages=[{"role": "user", "content": "Hello"}])
4 print(chat.choices[0].message.content)
5 text = client.audio.transcriptions.create(
      model="whisper-1", file=open("meeting.mp3", "rb")).text
6 print(text)

Both models come from the gallery. For the second call, install whisper-1 from the gallery.
