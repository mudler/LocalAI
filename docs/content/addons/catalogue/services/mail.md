Agents can read a mailbox over IMAP and, if you allow it, write mail over SMTP. It works with any provider that offers both protocols.

## At a glance

| Topic | Detail |
|---|---|
| What it adds | List folders, search, read a message or a conversation, read the text of a text attachment, and send or save a plain text email. It never deletes, moves, flags or forwards mail. |
| Needs | A connection with the mailbox address, the username, the password (an app password if your provider offers one) and the IMAP and SMTP server names. |
| Guide | [Mail in Chat apps and connections]({{% relref "/features/chat-apps/accounts#mail-imap-and-smtp" %}}) |

Whatever the agent reads is sent to the chat's model.
