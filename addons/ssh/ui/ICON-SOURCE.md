# Icon source

Not a logo. `icon.png` is a generated tile: a terminal glyph from the add-on icon set (`addons/internal/uibuild/glyphs.mjs`) on the add-on colour.

Why no brand mark: SSH is a protocol and OpenSSH is a project, and neither has a mark that the add-on should use as its own. A generic terminal glyph says what the add-on does.
