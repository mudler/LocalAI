Get started

Running in minutes.

Install LocalAI, run a model, then open it in your browser.

  1. Install it

    Use the script on Linux and on a Mac with Apple Silicon, a container on any platform, or the desktop app on Linux and macOS.

    {{ partial "install.html" . }}

  2. Start LocalAI

    The script installs the program and does not start it. This command starts the server. The first time a model needs an engine, LocalAI downloads it.

    $local-ai

  3. Open it and pick a model

    Go to http://localhost:8080 in your browser. On a fresh install, the page recommends a model for your hardware. Accept it, then start a chat. The API is on the same address. To run a model directly, name it: local-ai run gemma-4-e2b-it-qat-q4_0 is a small model that runs on a CPU.

  4. Add more

    Ask an admin to install add-ons such as Office or Sandbox, and to turn on the features your team needs.

    New in LocalAI 5.0. Needs 5.0 or newer.
