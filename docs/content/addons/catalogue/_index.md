Pick an add-on below. An administrator installs it, and anyone with the `addons` feature uses it. The [user guide]({{% relref "/addons/user-guide" %}}) has the steps, and each page says what that add-on needs.

## Chat apps

| Add-on | What it adds |
|---|---|
| [Telegram]({{% relref "/addons/catalogue/chat-apps/telegram" %}}) | Talk to a saved agent from Telegram. |
| [Slack]({{% relref "/addons/catalogue/chat-apps/slack" %}}) | Talk to a saved agent from Slack. |
| [Discord]({{% relref "/addons/catalogue/chat-apps/discord" %}}) | Talk to a saved agent from Discord. |

## Work tools

| Add-on | What it adds |
|---|---|
| [Simple Office]({{% relref "/addons/catalogue/work/office" %}}) | Make, read and edit Word, Excel, PowerPoint and PDF files, with no sandbox. |
| [Sandbox]({{% relref "/addons/catalogue/work/sandbox" %}}) | Run commands and code in an isolated sandbox with your files mounted. |
| [Tables]({{% relref "/addons/catalogue/work/tables" %}}) | Databases of tables that a chat can read and change, and that you can share. |
| [Calendar]({{% relref "/addons/catalogue/work/calendar" %}}) | A calendar that chats and agents can read and change. |
| [Contacts]({{% relref "/addons/catalogue/work/contacts" %}}) | An address book that chats and agents can search and change. |
| [Web search]({{% relref "/addons/catalogue/work/web" %}}) | Search providers with a key, and PDF reading, for the web tools of a chat. |

## Services and devices

| Add-on | What it adds |
|---|---|
| [Gmail]({{% relref "/addons/catalogue/services/gmail" %}}) | Read mail, and save and send drafts with your approval. |
| [Mail]({{% relref "/addons/catalogue/services/mail" %}}) | Read a mailbox over IMAP and write mail over SMTP. |
| [Google Drive]({{% relref "/addons/catalogue/services/google-drive" %}}) | Read Drive folders you choose, and write text files if you allow it. |
| [GitHub]({{% relref "/addons/catalogue/services/github" %}}) | Read repositories, issues and pull requests, and comment if you allow it. |
| [Jellyfin]({{% relref "/addons/catalogue/services/jellyfin" %}}) | Search a Jellyfin library and see what is playing. |
| [Home Assistant]({{% relref "/addons/catalogue/services/home-assistant" %}}) | Read a smart home, and switch things within limits you set. |
| [PiKVM]({{% relref "/addons/catalogue/services/pikvm" %}}) | Check the status of a PiKVM. If you allow it, press its power buttons and type on its keyboard. |
| [SSH]({{% relref "/addons/catalogue/services/ssh" %}}) | Run a command on a remote machine, with a confirmation each time. |

## Models and media

| Add-on | What it adds |
|---|---|
| [Studio]({{% relref "/addons/catalogue/models-and-media/studio" %}}) | A page to make images, video, 3D, speech and sound, and keep what you make. |
| [Talk]({{% relref "/addons/catalogue/models-and-media/talk" %}}) | A spoken conversation with a model. |
| [Voice]({{% relref "/addons/catalogue/models-and-media/voice" %}}) | Voice recognition, the voice library and text to speech. |
| [Face]({{% relref "/addons/catalogue/models-and-media/face" %}}) | Identify a face in a photo, or check whether two photos show the same person. |
| [Fine-tuning]({{% relref "/addons/catalogue/models-and-media/fine-tuning" %}}) | The Fine-Tune page and chat tools for fine-tuning jobs. |
| [Quantization]({{% relref "/addons/catalogue/models-and-media/quantization" %}}) | The Quantize page and chat tools for quantization jobs. |
| [Pirate Face search]({{% relref "/addons/catalogue/models-and-media/pirateface-search" %}}) | Search Pirate Face for open models from the Models page. |

To build an add-on, see [Build your own add-on]({{% relref "/addons/build-your-own" %}}).
