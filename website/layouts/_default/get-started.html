Get started

Running in minutes.

Install LocalAI, run a model, then open it in your browser.

  1. Install it

    Use the script on Linux and on a Mac with Apple Silicon, a container on any platform, or the macOS app.

    {{ partial "install.html" . }}

  2. Run a model

    This downloads the model from the gallery and starts it. The first run also downloads the engine the model needs.

    $local-ai run qwen3-4b

  3. Open it

    Go to http://localhost:8080 in your browser and start a chat. The API is on the same address.

  4. Add more

    Ask an admin to install add-ons such as Office or Sandbox, and to turn on the features your team needs.
