This catalogue lists the add-ons in the official add-on library. Each page says what the add-on adds, who installs it and who turns it on, and links to its guide. In the current development builds, the add-ons are in the development channel of the add-on library, so they can change.

An administrator installs an add-on. A person who has the `addons` feature uses it. See the [user guide]({{% relref "/addons/user-guide" %}}) for the steps.

## Chat apps

| Add-on | What it adds |
|---|---|
| [Telegram]({{% relref "/addons/catalogue/chat-apps/telegram" %}}) | A Telegram bot for one saved agent. |
| [Slack]({{% relref "/addons/catalogue/chat-apps/slack" %}}) | A Slack app for one saved agent. |
| [Discord]({{% relref "/addons/catalogue/chat-apps/discord" %}}) | A Discord bot for one saved agent. |

## Work tools

| Add-on | What it adds |
|---|---|
| [Simple Office]({{% relref "/addons/catalogue/work/office" %}}) | Make, read and edit Word, Excel, PowerPoint and PDF files, with no sandbox. |
| [Sandbox]({{% relref "/addons/catalogue/work/sandbox" %}}) | Run commands and code in an isolated sandbox with your files mounted. |
| [Tables]({{% relref "/addons/catalogue/work/tables" %}}) | Databases of tables that a chat can read and change, and that you can share. |
| [Calendar]({{% relref "/addons/catalogue/work/calendar" %}}) | A calendar inside LocalAI that agents read and keep. |
| [Contacts]({{% relref "/addons/catalogue/work/contacts" %}}) | An address book inside LocalAI that agents look up and keep. |
| [Web search]({{% relref "/addons/catalogue/work/web" %}}) | Search providers with a key, and PDF reading, for the web tools of a chat. |

## Services and devices

| Add-on | What it adds |
|---|---|
| [Gmail]({{% relref "/addons/catalogue/services/gmail" %}}) | Read mail, and save and send drafts with your approval. |
| [Mail]({{% relref "/addons/catalogue/services/mail" %}}) | Read a mailbox over IMAP and write mail over SMTP. |
| [Google Drive]({{% relref "/addons/catalogue/services/google-drive" %}}) | Read Drive folders you choose, and write text files if you allow it. |
| [GitHub]({{% relref "/addons/catalogue/services/github" %}}) | Read repositories, issues and pull requests, and comment if you allow it. |
| [Jellyfin]({{% relref "/addons/catalogue/services/jellyfin" %}}) | Search a media library and see what plays. |
| [Home Assistant]({{% relref "/addons/catalogue/services/home-assistant" %}}) | Read a smart home, and switch things within limits you set. |
| [PiKVM]({{% relref "/addons/catalogue/services/pikvm" %}}) | Check a PiKVM, and press power buttons and type if you allow it. |
| [SSH]({{% relref "/addons/catalogue/services/ssh" %}}) | Run a command on a remote machine, with a confirmation each time. |
