# Icon source

`icon.png` is the Slack logo mark from Simple Icons (https://simpleicons.org), version 15.22.0, file `icons/slack.svg` (https://www.npmjs.com/package/simple-icons/v/15.22.0). The Simple Icons data is CC0 1.0.

The Slack name and logo are trademarks of their owner. The mark is used only to identify the service this add-on connects to. It does not say that Slack made, endorses or supports the add-on.

How the tile was made: a 256 by 256 PNG with the same rounded tile (corner radius 56) as the other add-on icons, filled with the add-on colour #4a154b. The mark is a single white shape, 132 pixels wide, centred on the tile. The mark was not changed except for colour and size.

Simple Icons removed its Slack mark in version 16.0.0, so this icon uses 15.22.0, the last version that has it.
