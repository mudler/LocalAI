## Installation Methods

Choose the installation method that best suits your needs:

1. **[Containers]({{% relref "/start/install/containers" %}})** ⭐ **Recommended** - Works on all platforms, supports Docker and Podman
2. **[macOS]({{% relref "/start/install/macos" %}})** - Download and install the DMG application
3. **[Linux]({{% relref "/start/install/linux" %}})** - Install on Linux using binaries
4. **[Kubernetes]({{% relref "/start/install/kubernetes" %}})** - Deploy LocalAI on Kubernetes clusters
5. **[Build from Source]({{% relref "/contributing/build-from-source" %}})** - Build LocalAI from source code
