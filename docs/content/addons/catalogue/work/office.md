Ask a chat to make, read and edit Word, Excel, PowerPoint and PDF files. It doesn't need Sandbox.

## At a glance

| Topic | Detail |
|---|---|
| What it adds | 11 tools: read, edit and create for Word, Excel and PowerPoint, and read and create for PDF. Results land in your Files. It runs on Linux and macOS. |
| Needs | Nothing else. It doesn't need Sandbox. |
| Guide | [Office documents]({{% relref "/features/files-and-documents/office" %}}) |

If you need exact control of the layout, Sandbox can build the same files with Python. You can install either one without the other. See [Sandbox: run Python on your files]({{% relref "/addons/catalogue/work/sandbox" %}}).
