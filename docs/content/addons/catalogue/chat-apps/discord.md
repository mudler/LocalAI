Connect a Discord bot to one of your saved agents. People talk to the agent in a direct message with the bot, or by mentioning the bot in a channel or thread of a server.

## At a glance

| Topic | Detail |
|---|---|
| What it adds | A Discord bot for one saved agent. The add-on keeps a Gateway link to Discord, so LocalAI needs no public address. |
| Needs | The Saved agents (`agents`) and Chat connectors (`connectors`) permissions, both off by default for new users on a server with accounts. A Discord bot token with the Message Content Intent on. A new bot answers nobody until you add its allowed senders. |
