# Icon source

Not an official logo. `icon.png` is a generated tile: a hash glyph from the add-on icon set (`addons/internal/uibuild/glyphs.mjs`) on the add-on colour.

Why no official mark: the Slack media kit (https://slack.com/media-kit, https://slack.com/brand-guidelines) hands out its logo files through a Brandfolder that needs a sign-in (https://brandfolder.com/slack), so the file could not be fetched. The guidelines page says the marks may be used without a separate agreement, but only as the guidelines allow. Using the mark as the icon of a third-party add-on needs a decision by the project owner.
