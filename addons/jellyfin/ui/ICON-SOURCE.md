# Icon source

Not an official logo. `icon.png` is a generated tile: a play glyph from the add-on icon set (`addons/internal/uibuild/glyphs.mjs`) on the add-on colour.

Why no official mark: https://jellyfin.org/docs/general/contributing/branding/ says: do not use the Jellyfin logo as the logo of any project or service without the team's permission. That forbids this use, so the generated tile stays unless the Jellyfin team agrees.
